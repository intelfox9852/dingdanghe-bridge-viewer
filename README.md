# 叮当河特大桥三维查看器

GitHub Pages 静态查看器：WebGPU 优先，保留 WebGL2 回退。12 联、46 跨，11458 个构件；支持选择、测量、四边形线框、横断面与三维短段。

包含最新 30m 通用图和第3联 25.5m 箱梁、4780 束正式纵向钢束、修正后的齿板和有效排水构造。已排除用户确认的打叉废图构造。

实景按1700×600m测绘范围裁剪，离线重建253个各级LOD并修复纹理黑边及内部小孔；原始全分辨率数据留在本地。网页直接显示重建结果，没有运行时绿色占位和后台纹理替换。缺摄影覆盖的地形采用截图取样深灰绿色#3d5b50。缺失摄影细节不能由补面恢复，扫描凸起仍保留。

桥梁坐标和属性用无损压缩包，由Worker后台读取。模型用于浏览与深化，尺寸和图纸冲突详见工程依据。本仓库不含DWG原件、凭据、CAD缓存或完整实景数据集。Three.js及3d-tiles-renderer版权与许可保留在vendor目录。

Android与其他手机默认读取轻量显示包：保留全部11458个构件，桥梁首屏传输约12.8MB；钢束显示中心线偏差不超过2.1mm，混凝土网格拓扑不变。完整原始参数在首次点击构件时按需读取，属性包约0.2MB。移动端默认实体显示、普通蓝色水面、实景关闭，可手动开启或切换“完整精度”。桌面默认完整模型；完整模型数据与坐标未改动。

新增[纯实景快速入口](./oblique_three.html)：不读取桥梁及钢束，先显示完整顶层，再按视野加载近景；菜单支持原版LOD对照。优化的253个实景瓦片由31.32MB降至9.92MB，顶层约0.22MB；采用Meshopt和WebP，244个细级瓦片的有效几何保持一致，原始图像经过有损压缩。河岸原始破洞仍有残留，本轮主要改善加载，不代表完整摄影修复。
