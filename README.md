# 叮当河特大桥三维查看器

GitHub Pages 静态查看器：WebGPU 优先，保留 WebGL2 回退。12 联、46 跨，11458 个构件；支持选择、测量、四边形线框、横断面与三维短段。

包含最新 30m 通用图和第3联 25.5m 箱梁、4780 束正式纵向钢束、修正后的齿板和有效排水构造。已排除用户确认的打叉废图构造。

实景使用2026年11月12日接入的重新处理数据，按1700×600m测绘边界筛选并显示裁剪。完整25,322个GLB（4,289,327,016字节）由腾讯云COS南京地域托管；保留原始几何、纹理及完整LOD，不另作减面、纹理降采样或层级截断。跨边界瓦片采用显示裁剪，摄影缺覆盖处保留测绘地形。原始摄影中的噪点或缺失不代表已修复。

桥梁坐标和属性用无损压缩包，由Worker后台读取。模型用于浏览与深化，尺寸和图纸冲突详见工程依据。本仓库不含DWG原件、凭据、CAD缓存或完整实景数据集。Three.js及3d-tiles-renderer版权与许可保留在vendor目录。
