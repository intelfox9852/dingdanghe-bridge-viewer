# 叮当河特大桥三维查看器

GitHub Pages 静态查看器，WebGPU优先，保留WebGL2回退。

12联、46跨、双幅，包含施工块件、纵向钢束、三维测绘地形与参考水面；支持分层显隐、实际模型横断面、测量、四边形线框及1522个下部与支承独立单体。

每幅2车道，两端各100m路基延伸。标线细节、路基断面与缺测地形补面为展示推定；图纸缺项和冲突详见建模说明及一般构造核查报告。模型用于浏览与深化，不作为施工放样或精确算量依据。

模型和OBJ使用gzip压缩；网页自动解压模型，OBJ下载后需解压。需要支持WebGPU或WebGL2和DecompressionStream的现代浏览器。Three.js及OrbitControls遵循MIT许可，源码保留版权声明。

此仓库只包含静态查看器、必要模型及工程依据，不包含DWG原图、凭据、CAD解析缓存或本地试验数据。
